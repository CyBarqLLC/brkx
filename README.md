# BRKX

موقع متجر BRKX لقصي قنديل في الأردن. الموقع مبني بـ HTML وCSS وJS فقط، بدون أي build، ويشتغل مباشرة على GitHub Pages.

## الرفع على GitHub

```bash
cd ~/Desktop/WORK/brkx/brkx-website && git add -A && git commit -m "Update" && git pull --rebase origin main && git push origin main
```

## المنتجات والأسعار: ملف واحد

كل المنتجات موجودة في `assets/js/products.js`. الصفحة كلها (الهيرو والمتجر والإطلالات والسلة) تُبنى من هذا الملف.

| ماذا تريد | ماذا تعدّل |
|---|---|
| تغيير سعر | `price` داخل المنتج، مثلًا `price: 14.5` |
| رسوم التوصيل | `delivery: 1` أعلى الملف |
| إضافة لون | سطر جديد داخل `colours` فيه الاسم بالعربي والإنجليزي، ولون الدائرة `hex`، والصورة `img` |
| منتج بدون مقاسات (عطر، إكسسوار...) | ضع `sizes: null` |
| شارة على المنتج | `badge: { ar: 'جديد', en: 'New' }` |
| إظهار المنتج في الهيرو المتبدّل | أضف `hero: { clips: ['لون1', 'لون2'] }` (يستخدم فيديوهات الألوان) |
| إخفاء منتج مؤقتًا | احذفه من القائمة أو ضع أمامه `//` |

### إضافة منتج جديد

انسخ أي منتج موجود داخل `products: [ ... ]`، وغيّر `id` لاسم قصير جديد بالإنجليزي، ثم عدّل الاسم والسعر والصور. ضع الصور في `assets/img` والفيديوهات في `assets/video`.

صورة البطاقة بنسبة 3:4 (عرض 640 بكسل يكفي، ونسخة 1080 اختيارية في `imgLarge`).

### أقسام جديدة (غير الملابس)

الأقسام معرّفة في `categories` أعلى الملف: بلايز، إكسسوارات، منتجات أخرى. أضف قسمًا جديدًا بنفس الشكل. أزرار التصفية في المتجر تظهر تلقائيًا بمجرد وجود منتجات في أكثر من قسم.

## الطلب

الزائر يختار المنتج واللون والمقاس، ويضيفه للسلة. السلة تحفظ نفسها في متصفحه. زر "أرسل الطلب عبر واتساب" يفتح محادثة مع الرقم في `phone`، برسالة جاهزة فيها كل القطع، والمجموع، والتوصيل، والإجمالي، والاسم والمحافظة إن كتبها.

رابط مباشر لأي منتج: `brkx.store/#p-crew` أو مع لون: `brkx.store/#p-crew-beige`. مفيد لوضعه في إنستغرام.

## بعد أي تعديل على CSS أو JS

غيّر رقم النسخة `?v=...` في روابط الملفات داخل `index.html`، حتى لا يعرض متصفح الموبايل نسخة قديمة.

## الكشيدات

خط ثمانية يحتوي على كشيدات منحنية مدمجة. حرف التطويل `ـ` بعد حرف في عنوان يتحول لامتداد ناعم، مثل `المـدورة`. كشيدة واحدة كحد أقصى في الكلمة، وفي العناوين الكبيرة فقط.
