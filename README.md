# BRKX

موقع متجر BRKX لقصي قنديل في الأردن. الموقع مبني بـ HTML وCSS وJS فقط، بدون أي build، ويشتغل مباشرة على GitHub Pages.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub، مثلًا باسم `brkx`.
2. ارفع كل محتويات هذا المجلد كما هي، مع الحفاظ على ترتيب المجلدات.
3. من إعدادات المستودع افتح Settings ثم Pages، واختر Source: `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة تقريبًا سيكون الموقع متاحًا على `https://<username>.github.io/brkx/`.

## أماكن التعديل

| ماذا | أين |
|---|---|
| رقم واتساب | المتغير `PHONE` أعلى ملف `assets/js/main.js`، وروابط `wa.me` داخل `index.html` |
| رسائل الطلب على واتساب | `MSG` و`productMsg` في `assets/js/main.js` |
| النصوص بالعربي والإنجليزي | `index.html`: كل نص مكتوب مرتين، مرة داخل `data-l="ar"` ومرة داخل `data-l="en"` |
| الألوان والصور | بطاقات `.card` في `index.html`، والصور داخل `assets/img` |

## الكشيدات

خط ثمانية يحتوي على كشيدات منحنية مدمجة. عندما تكتب حرف التطويل `ـ` بعد حرف في عنوان، يستبدله الخط تلقائيًا بامتداد ناعم، مثل `عمّـان`. استخدم كشيدة واحدة كحد أقصى في الكلمة، وفي العناوين الكبيرة فقط.
